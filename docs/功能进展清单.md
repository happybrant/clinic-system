## 建议开发顺序（主闭环）

1. ~~门诊接诊工作台（病历 + 开方）~~ ✅
2. ~~收费单生成与收银~~ ✅
3. ~~药房审方发药 + 库存扣减~~ ✅（入库最小能力同步完成）
4. ~~盘点 / 供应商页 / 出入库流水~~ ✅
5. 基础报表 + 权限管理页补齐

---

## 联调说明（收费 → 药房）

1. **库存**：先在「库存 → 采购入库」保存并过账，保证处方药品有批次库存  
2. **门诊**：接诊开方并提交处方  
3. **收费**：待收费处方 → 生成并收银（自动创建待发药单）  
4. **药房**：待发药 → 审方（可选）→ 确认发药（FEFO 扣库存）
